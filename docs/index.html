Что внутри

Бот сделан так, чтобы заказчик мог менять содержимое сам, а разработчик подключался только к логике.

FAQ правит заказчик

Вопросы и ответы лежат в data/faq.json. Добавить пункт — значит дописать две строки в файл: кнопки в меню и обработчик ответа строятся из него автоматически.

Заявки сохраняются

Пошаговый диалог собирает имя и вопрос, показывает их на проверку и после подтверждения дописывает заявку в data/leads.json вместе с логином и временем.

Курсы через провайдер

Источник курсов выбирается переменной RATE_PROVIDER: демо-значения без сети или реальный API. Интерфейс один, поэтому подменить источник — одна строка в конфиге.

Токен только из окружения

Ключ бота читается из BOT_TOKEN, в репозитории лежит лишь .env.example. В коде токена нет ни в одном коммите.

Тесты без сети и токена

11 тестов на pytest проверяют меню, ответы FAQ, весь сценарий заявки с отменой и разбор ответа курсов — не обращаясь ни к Telegram, ни к внешнему API.

Меняется под заказчика

Разделы меню, тексты и прайс — обычные константы и файлы данных. Под конкретный бизнес меняется содержимое, а не архитектура диалога.

Запуск

Нужен только Python и токен от @BotFather.

git clone https://github.com/Olegg000/python-faq-bot
cd python-faq-bot
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # вписать BOT_TOKEN
python -m bot

# тесты — без токена и без сети
pytest
